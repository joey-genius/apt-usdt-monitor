数据来源与计算说明

价格、资金费率、多空比、持仓历史及成交净额来自 Binance USDT 本位永续接口；Bybit 和 OKX 仅用于持仓分布。Binance 持仓名义价值 = 持仓币数 × 标记价格。各接口采样时间可能不同，多空比不是逐笔实时数据。

大户指标来自交易所的 Top Trader 统计；账户比按账户数量，持仓比按头寸比例。168小时指标需要足够历史数据，缺失时显示“—”，不会补造。演示模式中的所有数值均为模拟数据，不是截图中的 DASH 数据，也不代表 APT 实际行情。

线上版由浏览器直接读取交易所公开 API，无需保持本地电脑开机；接口可能受访问者网络、地区、跨域策略或频率限制影响。本软件不需要 API 密钥，关闭页面后不会继续后台监测。
