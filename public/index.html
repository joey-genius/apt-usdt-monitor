数据来源与计算说明

覆盖 Binance、Bybit、OKX、Bitget、Gate、Hyperliquid 的 APT 永续合约，不代表全市场。价格 = Σ(价格 × 单边名义持仓) / Σ有效持仓；各平台费率先换算为8小时等效费率，再按持仓加权。这是比较指标，不是任何交易所的实际结算费率。

Bybit 使用 singleOpenInterestValue；Gate 使用 position_size × quanto_multiplier × mark_price。Hyperliquid 是 USDC 保证金合约，以1 USDC = 1 USD近似合并。各平台采样时间不同，不与 CoinGlass 保证一致。

多空情绪是持仓加权代理指数，不是全市场实际账户人数比；大户定义因平台而异。每项列出实际参与交易所与最早采样时间。历史变化按同组配对计算，曲线使用当前固定持仓权重，不是历史持仓加权指数。行情背景中的主动买卖净额未按大额阈值筛选，不能识别主力资金；不用于填补大额成交缺失数据。

大额成交买卖净额仅针对达到所选金额的交易所上报成交记录，不代表原始委托或账户。近期接口有条数上限，覆盖与连续性判断存在限制，不保证全市场完整。金额按 USD 等值汇总；净额 = 主动买入 − 主动卖出，记录数不是订单数或账户数。逐行披露精确窗口、来源和排除原因；强平、订单簿与地址追踪均未接入。

线上由浏览器直连公开 API，受网络、地区和跨域策略影响。关闭页面后不再后台刷新；演示数据均为模拟值，未提供大额成交记录。CoinGlass 官方 API 需密钥，本站没有使用其私有接口或将静态网页数值当实时数据。
